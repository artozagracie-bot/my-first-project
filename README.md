# Sky Hopper

A small, dependency-free Flappy Bird-style browser game made with HTML Canvas and vanilla JavaScript.

## Play

Open index.html in a browser, or serve this folder locally:

    python -m http.server 8000

Then visit http://localhost:8000.

Tap or click, or press Space / Up Arrow, to flap. Fly through the gaps without hitting a pipe or the ground. Your best score is saved in your browser.
